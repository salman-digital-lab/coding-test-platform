# Coding Test Platform

## Feature

### Homepage

User will input the unique token that will linked to an email that already inputted in the database. If the token is valid, the user will be redirected to the test page.

### Test Page

User will be able to answer the question and submit the answer. the language that can be used is Javascript so the grader should be in the client side. It will send the score to the backend. The list of question and answer will be hardcoded inside the client side frontend.

### Admin Page

It should contain 3 pages, the first one is to input the email dan generate unique token. The second one is to see the result of the test.
